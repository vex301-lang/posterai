# AI 포스터 디자인 스튜디오

행사 제목, 일시, 장소, 분위기, 참고 이미지, 행사 사진을 입력해 AI 포스터 시안 3개를 생성하는 Streamlit 앱입니다.

## 새 기능: 자연어 수정

생성된 시안 중 하나를 선택하고 `배경을 파스텔톤으로 바꿔줘`, `인물 사진을 더 크게 보여줘`, `오른쪽에 꽃 장식을 추가해줘` 등의 명령을 입력하면 OpenAI 이미지 편집 API로 선택한 시안만 수정합니다. 여러 번 수정할 수 있으며, **이전 디자인으로 되돌리기** 버튼도 있습니다.

한글 행사 정보는 생성 이미지와 별도로 합성합니다. 행사 제목, 일시, 장소 등 **글자 자체를 변경**하려면 사이드바 입력값을 바꾸세요. API 호출 없이 다운로드 이미지에 반영됩니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit Cloud에서는 GitHub 저장소의 `app.py`, `requirements.txt`를 배포하세요. `OPENAI_API_KEY`를 Streamlit Secrets에 설정하거나 앱에 직접 입력할 수 있습니다.

## 주의

- 이미지 생성 3회 및 자연어 수정 1회마다 API 비용이 별도로 발생합니다.
- 원본 사진 속 인물이나 사물은 이미지 편집 과정에서 일부 달라질 수 있습니다.
- PNG는 시안용입니다. 대형 인쇄 전 해상도와 한글 문구를 검수하세요.
- 이미지 모델 이용 권한은 OpenAI 계정 설정에 따라 다를 수 있습니다.
